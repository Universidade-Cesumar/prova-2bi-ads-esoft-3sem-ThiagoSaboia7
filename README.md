# 📦 Controle de Almoxarifado - Missão Final

> **Link do Projeto:** [CLIQUE AQUI PARA ACESSAR O PROJETO](https://github.com/Universidade-Cesumar/prova-2bi-ads-esoft-3sem-ThiagoSaboia7) 🚀

Este projeto é uma ferramenta de gestão de estoque desenvolvida para o controle de entrada e saída de materiais em um almoxarifado. A aplicação consome uma API externa para persistência de dados e oferece alertas visuais para itens com baixo estoque.

## 🎯 Objetivo da Missão
Finalizar o produto implementando:
- Barra de pesquisa funcional.
- Dashboard com contagem total de itens.
- Alertas visuais para estoque baixo (crítico).
- Tratamento de erros em requisições `fetch` com blocos `try/catch`.
- Deploy em ambiente de nuvem.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **CSS3** (Estilização personalizada e alertas visuais)
- **JavaScript (ES6+)** (Lógica de filtragem, DOM e consumo de API)
- **MockAPI** (Simulação de backend para armazenamento)

## 📋 Requisitos Técnicos Atendidos (Contrato)
Conforme exigido no contrato técnico da aplicação:
- [x] **Busca:** Input com `id="input-busca"`.
- [x] **Dashboard:** Exibição do total de itens com `id="total-itens"`.
- [x] **Alerta de Estoque:** Itens com quantidade menor que 10 recebem automaticamente a classe `.estoque-critico`.
- [x] **Robustez:** Tratamento de erros implementado em todas as chamadas `fetch` para evitar falhas silenciosas.
